Before copying this setup · source and compatibility notes

This preserves Sam's recorded top-to-bottom order. It is not a proposed reorder or a guarantee that every mod is compatible. The Creation Club Content banner is not a separate numbered mod.

File sizes and menu versions are copied from the recording, not live download measurements. Rounded sizes are retained exactly. The displayed 14.97 GB is the console's total, not a sum of rounded rows.

Thumbnails are cropped from the actual Creations menu in Sam's supplied video, not newly retrieved Bethesda web listings. Generic placeholder images are preserved as shown. Names are the workbook's identifications; expand an entry for its clipped console title and recording timestamp. Entries 115, 136, 170 and 215 have identification qualifications.

The recorded #172 port description warns against Lux / Lux Orbis, while Lux is enabled at #219. The workbook also records an unresolved Thaumaturgy / Summermyst overlap (#25 / #26). These are retained cautions, not a crash diagnosis or instructions to change the order.
